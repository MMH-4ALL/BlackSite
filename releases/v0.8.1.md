# BlackSite v0.8.1 — Weapon Inspection

- Tap **F** or **Y** to play a complete 2.4-second inspection on any of the eight weapons. The gun lifts, turns and returns automatically; no held key is required.
- The original **hold V** inspection remains available.
- Flashbangs now use **H** so F never throws a grenade. Smoke remains on **G**. HUD hints, Field Manual and README show the controls.
- Firing, reloading, scoping, utility, weapon switches and round resets interrupt inspection. Pause freezes it. Aim, ammo, damage, accuracy, recoil and other weapon statistics are unchanged.

Validation: gameplay/model/animation suite and real Chromium WebGL/input suite pass, including F/Y on every weapon, pause/automatic return/cancellation, no accidental grenade use, H flash input, buy lock/timer and existing map/team/objective regressions. Source and test changes are in this patch; the v0.8.0 release remains available.
